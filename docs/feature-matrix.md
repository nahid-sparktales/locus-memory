# Feature matrix: 0.3.0

Implementation is present across `locus-memory` and Locus. The current
[release validation record](release-0.3.0.md) distinguishes package checks from
host application and live-provider checks. The [0.1.0 matrix](feature-matrix-0.1-baseline.md)
retains its original detailed test evidence and historical limitations.

| Area | Package | Locus integration | Acceptance state |
|---|---|---|---|
| Ownership and installation | Authoritative native vault, rollback, fresh bootstrap | Exact bundled wheel, thin adapters | Existing 0.2.1 cutover preserved; no repeat migration |
| Inspector | Encrypted submission references, scoped explanations, final revision metadata | Turn/run UI, provider-boundary receipts, authenticated inspection | Package receipt/scope tests; host Swift checks recorded separately |
| Current evidence | Exclude corrected history; preference/evidence distinction; qualifier checks | Production runtime uses conservative relevance policy | Frozen held-out verification recorded in release validation |
| Agent coverage | Native option defaults false; existing scoped policy retained | Primary, saved, team, helper, scheduled, evaluation paths; helper candidates require review | Host coverage verification recorded separately |
| Semantic search | Encrypted vectors and lexical/semantic fusion | Optional installed Ollama model; no download; loopback/no redirects/proxies; deadline/fallback | Adapter tests passed; no embedding model available for quality gate; keyword default |
| Verified learning | Stable episodes, independent evidence counting, procedure state machine and revocation | TaskStateStore/TaskVerifier authority, automatic terminal capture, suite binding and human review UI | Package evidence/governance tests; host/UI verification recorded separately |
| Saved-chat search | AES-256-GCM session envelopes plus RAM FTS; incremental hydration | Host keys/partition, exclusive upgrade lease, shutdown integration | Encrypted cache upgrade, failure/restart and plaintext-canary tests |
| Restore protection | Injectable mirror; ancestor-MAC divergence and monotonic gap recovery | Signed macOS login-Keychain helper, offline custody/recovery | Package fork/recovery tests; signed host helper audit recorded separately |
| Paired task outcomes | Preserved original benchmark plus separate production evaluation | Reserved cost/token budget; fixed fixtures; learning disabled | Small local campaign: 2/6 on, 2/6 off; no quality gain demonstrated |

The campaign ceiling is $10 and 250,000 tokens across all requests. Unknown billable pricing
is ineligible. Baseline results are never overwritten. [Validation record](release-0.3.0.md).
